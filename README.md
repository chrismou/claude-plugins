# chrismou-claude-plugins

Marketplace index for Chris Chrisostomou's Claude Code plugins.

## Usage

```bash
claude plugin marketplace add chrismou/claude-plugins
```

## Plugins

| Plugin | Description | Repo |
| --- | --- | --- |
| project-manager | End-to-end AI dev loop orchestrating a team of specialised agents through a plan → implement → review → document cycle. | [chrismou/claude-project-manager-workflow](https://github.com/chrismou/claude-project-manager-workflow) |

## Installation

```bash
claude plugin install project-manager@chrismou-claude-plugins
```
