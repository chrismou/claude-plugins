# chrismou-claude-plugins

Marketplace index for Chris Chrisostomou's Claude Code plugins.

## Usage

```bash
claude plugin marketplace add chrismou/claude-plugins
```

## Commands

| Plugin                   | Description                                                                                                             | Repo                                                                                                    |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| chrismou-project-manager | End-to-end AI dev loop orchestrating a team of specialised agents through a plan → implement → review → document cycle. | [chrismou/claude-project-manager-workflow](https://github.com/chrismou/claude-project-manager-workflow) |

### Installation

```bash
claude plugin install chrismou-project-manager@chrismou-claude-plugins
```

## Hooks

| Plugin           | Description                                                                                                                                | Repo                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------- |
| desktop-notifier | Native desktop notification (Linux notify-send / macOS Notification Center) naming the project when a Claude Code session needs attention. | [chrismou/claude-desktop-notifier](https://github.com/chrismou/claude-desktop-notifier) |

### Installation

```bash
claude plugin install desktop-notifier@chrismou-claude-plugins
```
